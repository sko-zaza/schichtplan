# Schichtplan Eisbahn Bruchhausen-Vilsen

Web-App für die Schichtplanung der Kunsteisbahn (Saison 2026/27) – Koncak & Co.

- Mitarbeiter legen sich mit Name + PIN ein Konto an und tragen sich in Schichten ein.
- Eingetragene Schichten kann nur die Person selbst oder die Chefin freigeben.
- Verdienst: 13,90 €/Std. bis 31.12.2026, ab 1.1.2027 14,60 €/Std. (Mindestlohn).
- Daten liegen in Supabase (Region Frankfurt). `setup.sql` enthält das Datenbank-Schema.
